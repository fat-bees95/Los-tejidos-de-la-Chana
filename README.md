# Los tejidos de la Chana

Sitio web artesanal para mostrar productos tejidos a mano, incluyendo accesorios, decoración y juguetes. Cada sección cuenta con una galería visual y un formulario de contacto.

## Secciones del Sitio

- **Página principal** (`index.html`) — Introducción al sitio.
- **Accesorios** (`Accesorios_Chana3.1.html`) — Galería de productos como carteras, bolsos, etc.
- **Decoración** (`Decoración_Chana3.1.html`) — Canastos, alfombras, caminos de mesa, etc.
- **Juguetes** (`Juguetes_Chana3.1.html`) — Amigurumis, muñecos y juguetes tejidos.
- **Página de agradecimiento** (`gracias.html`) — Mostrada luego de enviar un formulario.

## Archivos Principales

- `estilos.css` — Estilos globales del sitio.
- `Modal_Chana3.1.js` — Script para el efecto modal al hacer clic en imágenes.
- `gracias.html` — Página mostrada tras el envío del formulario.
- `README.md` — Este archivo.
